# Nexora AI

> Research Smarter. Discover Faster.

Nexora AI is an AI-powered research assistant that helps students, researchers, and professionals understand research papers, generate literature reviews, detect research gaps, chat with PDFs, create citations, flashcards, and much more.

## 🚀 Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python

### AI
- Gemini API
- LangChain
- LangGraph

### Database
- PostgreSQL

### Vector Database
- Qdrant
